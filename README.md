# notespace-mern

A simple full-stack note-taking application built with the MERN stack.

- Live Demo : https://notespace-mern.vercel.app

## Features

- Create, edit, and delete notes
- View and manage notes
- REST API backend
- MongoDB database
- React-based frontend

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- daisyUI
